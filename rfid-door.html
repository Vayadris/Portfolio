RFID Door Lock Project

Technical Overview: ESP-32 | C++ | PlatformIO

Project Description

This project involved building a fully functional RFID-based door lock system, from wiring the hardware components to programming the access control logic on an ESP-32.

Key Features

  • RFID Reader: Integrated an RC522 RFID module to read and authenticate authorized tags and cards.
  • Access Control: Programmed logic in C++ to grant or deny access based on stored authorized tag IDs.
  • Locking Mechanism: Wired a servo motor to operate as the locking mechanism, which engages or disengages based on access permissions.
  • Feedback System: Added LED and buzzer feedback to indicate whether access was granted or denied.
