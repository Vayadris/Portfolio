Space Invaders

Technical Overview: Python | Pygame | Arduino | Serial Communication

Project Description

A fully playable Space Invaders game built in Python using Pygame, controlled by a custom Arduino-based joystick controller. The game communicates with the hardware in real time over serial, translating physical joystick input and button presses into in-game actions.

Key Features

  • Hardware Controller: Built a custom joystick controller with an Arduino, sending real-time X/Y axis data and button inputs over serial at 115200 baud.
  • Multiple Abilities: Implemented three combat abilities — a standard shoot, a screen-wide laser, and a temporary shield — each with individual cooldown timers.
  • Progressive Difficulty: Enemies increase in speed and quantity each level, with alternating movement directions and random bullet fire.
  • Persistent High Score: The best score is saved to a local file and displayed on the HUD across sessions.
