Java Platformer Game

Technical Overview: Java | Animations | Audio | OOP

Project Description

I developed a 2D side-scrolling platformer using Java. This project allowed me to practice Object-Oriented Programming (OOP) concepts like inheritance and polymorphism for game entities.

Key Features

  • Optimization: Debugged and optimized the update loops for smoother gameplay.
  • Gameplay Mechanics: Implemented player movement, gravity, and collision detection using object-oriented programming.
  • Game Engine: Designed and developed a simple game engine to manage audio, input handling, and game state transitions.
  • Visuals & Animation: Integrated sprite images and tile maps to enhance visual quality and animation fluidity.
