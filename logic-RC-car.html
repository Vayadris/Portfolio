Logic-Gate Car

Technical Overview: Motor Control | Circuit Design | Hardware Debugging

Project Description

This vehicle was built to understand more about hardware parts I learned in ELEX 2120. The goal was to utilize hard-wired logic to create movement and different frequencies.

Key Features

  • Control System: Implemented a grayhill SPDT switch to control the car.
  • Logic Integration: Used logic gates to trigger sound effects based on specific sensor inputs.
  • Power Management: Integrated an L293D H-bridge to handle bidirectional motor control efficiently.
