Button Reaction Timer

Technical Overview: ESP-32 | C++ | PlatformIO | IIC OLED Display

Project Description

A hardware-based reaction time tester built around an ESP-32 microcontroller. The system randomly lights up one of four LEDs and measures how quickly the player presses the corresponding button, displaying the elapsed reaction time on an OLED screen in real time.

Key Features

  • Random LED Prompts: One of four LEDs is randomly activated to test the player's reaction.
  • Reaction Timing: The ESP-32 measures the time between the LED lighting up and the correct button being pressed.
  • OLED Feedback: An IIC OLED display shows the reaction time result immediately after each round so the player can track their performance.
  • Button & LED Mapping: Each of the four buttons corresponds to one LED, requiring the player to match the correct input to the lit output.
  • Embedded C++ Logic: Programmed in C++ using PlatformIO, handling GPIO input/output, timing, and display rendering on a single microcontroller.
